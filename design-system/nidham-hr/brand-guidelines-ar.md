## 1. جوهر البراند

| العنصر | التعريف |
|---|---|
| **الوعد** | «نِظام يدير شؤون موظفيك، عشان تتفرغ لشغلك.» |

## 2. الأسلوب البصري: Soft UI Evolution

عمق خفيف بظلال ناعمة وواضحة (مش Flat جامد ولا Neumorphism غامض)، تباين عالي يحقق WCAG AA كحد أدنى، حواف مستديرة معتدلة (10–14px)، ومساحات بيضاء منظمة بكثافة داشبورد (8–32px).

## 3. الألوان

### الأساسية
| الدور | Hex | الاستخدام |
|---|---|---|
| **الأزرق الأساسي** `--color-primary` | `#2563EB` | الأزرار الرئيسية، الروابط، العناصر النشطة، اللوجو |
| **الأخضر (الإنجاز)** `--color-accent` | `#059669` | أزرار الـ CTA التسويقية، حالات النجاح، «تم الصرف» |
| **الخلفية** | `#F8FAFC` | خلفية التطبيق والموقع |
| **النص الأساسي** | `#0F172A` | تباين 17.8:1 على الخلفية ✓ |
| **النص الثانوي** | `#475569` | تباين 7.5:1 ✓ |

### الحالات (Semantic)
| الحالة | لون النص | خلفية الشارة | مثال في نِظام |
|---|---|---|---|
| نجاح | `#059669` | `#ECFDF5` | حاضر، تم الصرف، عقد ساري |
| تحذير | `#B45309` | `#FFFBEB` | تأخير، عقد قارب على الانتهاء |
| خطأ | `#DC2626` | `#FEF2F2` | غائب، مرفوض، متأخر عن السداد |
| محايد | `#475569` | `#F1F5F9` | إجازة، معلّق |

**قواعد صارمة:**
- ممنوع كتابة hex مباشرة في الكود — استخدم التوكنز من `tokens.css` دايماً.
- ممنوع الاعتماد على اللون وحده لتوصيل معلومة (ضيف أيقونة أو نص مع كل حالة).
- الوضع الليلي له توكنز خاصة (`[data-theme='dark']`) — ممنوع «قلب» الألوان يدوياً.

## 4. الخطوط

| الاستخدام | الخط | الأوزان |
|---|---|---|
| **العناوين والتسويق** | Cairo | 700 / 800 |
| **الواجهات والنصوص** | IBM Plex Sans Arabic | 400 / 500 / 600 / 700 |
| **الأكواد والأرقام الثابتة** | IBM Plex Mono | 400 |

**قواعد عربية:**
- الحد الأدنى للنص الأساسي **16px** وخلايا الجداول **14px** — ممنوع أقل من 12px نهائياً.
- ارتفاع السطر للنص العربي **1.6** وللعناوين **1.3** على الأقل (عشان التشكيل وأذيال الحروف).
- الأرقام في الجداول المالية: أرقام غربية (0-9) بمحاذاة موحدة — أوضح في المرتبات والحسابات.
- ممنوع Italic للعربي (بيكسّر أشكال الحروف) — استخدم الوزن أو اللون للتمييز.

## 5. الاتجاه RTL

- الواجهة كلها RTL: `<html dir="rtl" lang="ar">`.
- استخدم خصائص CSS المنطقية (`margin-inline-start`، `padding-inline-end`، `text-align: start`) بدل left/right.
- الأيقونات الاتجاهية (أسهم، رجوع) لازم تنعكس في RTL. أيقونات الأشياء (تقويم، مستخدم، إعدادات) متتعكسش.
- الأيقونات: **Lucide أو Heroicons (SVG) فقط** — ممنوع استخدام إيموجي كأيقونات.
- الجداول: العمود الأول (الاسم) يمين، والأرقام محاذاة موحدة.

## 6. المكونات الأساسية

| المكوّن | المواصفات |
|---|---|
| زر رئيسي | ارتفاع 40px، خلفية `--color-primary`، نص أبيض 600، radius 10px، hover أغمق بـ transition 150ms |
| زر ثانوي | حدود `--color-border-strong`، خلفية شفافة، نفس الارتفاع |
| حقل إدخال | ارتفاع 40px، **Label ظاهر فوق الحقل دايماً** (مش placeholder بس)، رسالة الخطأ تحت الحقل مباشرة بالأحمر |
| بطاقة | padding 24px، radius 14px، ظل `--shadow-sm`، حد `--color-border` |
| صف جدول | ارتفاع 44px (هدف لمس مريح)، رأس الجدول خلفية `--color-muted` ووزن 600 |
| شارة حالة | radius كامل، padding 2px 10px، خط 12px وزن 600، لون + أيقونة |

## 7. الحركة

- المدة: 150–300ms للتفاعلات، easing قياسي `cubic-bezier(0.2, 0, 0, 1)`.
- الحركة بتوصّل معنى (ظهور، انتقال، تأكيد) — مش زينة.
- احترام `prefers-reduced-motion` إجباري.
- قوائم الداشبورد: stagger خفيف 60ms بين العناصر عند التحميل الأول فقط.

## 8. قائمة الفحص قبل التسليم

- [ ] كل الألوان من التوكنز (صفر hex مباشر في المكونات)
- [ ] تباين النصوص ≥ 4.5:1 في الوضعين الفاتح والغامق
- [ ] كل عنصر قابل للنقر: `cursor-pointer` + حالة hover + حالة focus ظاهرة
- [ ] أهداف اللمس/النقر ≥ 40×40px والجداول صفوفها ≥ 44px
- [ ] Labels ظاهرة لكل الحقول والأخطاء جنب حقولها
- [ ] أيقونات SVG فقط (Lucide/Heroicons) — صفر إيموجي
- [ ] الواجهة تشتغل RTL صح على مقاسات 1366 و1440 و1920 (ديسكتوب) و375 (موبايل ويب)
- [ ] `prefers-reduced-motion` محترم
